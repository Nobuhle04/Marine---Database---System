# PRG262 - Gym Management System

## Project Overview

This project was developed as part of the PRG262 Programming module at Belgium Campus.

It is a Windows Forms application built using C# and SQL Server to manage gym members and training programs. The system allows users to perform CRUD operations through a user-friendly interface.

## Technologies

- C#
- Windows Forms
- SQL Server
- ADO.NET

## Features

- User Login
- Member Management
- CRUD Operations
- Search Functionality
